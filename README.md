# 🤖 VPN Telegram Bot для панели 3x-ui

Готовый, простой в развертывании Telegram-бот для продажи и управления VPN-подписками через панель [3x-ui](https://github.com/MHSanaei/3x-ui).

## ✨ Возможности

- 🎁 **Пробный период**: Автоматическая выдача доступа на 3 дня при команде `/start`.
- 💳 **Оплата**: Прием платежей через Telegram Stars (⭐).
- 📊 **Личный кабинет**: Просмотр статуса подписки, ссылки для подключения и QR-кода.
- ⏳ **Уведомления**: Автоматическое предупреждение за 24 часа до конца подписки.
- 🔒 **Автоотключение**: Блокировка доступа в панели, как только истекает срок.
- 🖥 **Веб-админка**: Панель управления на FastAPI с авторизацией через Telegram (Magic Link).
- 🐳 **Docker**: Развертывание одной командой.
